# 云文档

在思源里浏览知识库、搜索标题和打开最近文档。

## 快速开始

1. 点击思源左侧的「云文档」图标，打开导航。
2. 点击知识库展开目录，再点一次收起。点击文件夹展开子项，点击文档打开正文。
3. 在首页搜索标题，用 ↑ / ↓ 选择结果，按回车打开，按 Esc 清空。也可以从「最近」打开文档。

## 常用操作

- **置顶**：右键文档，选择「置顶到快捷访问」。
- **管理目录**：右键文档或文件夹，使用思源原生菜单。
- **查看大纲和反链**：打开文档后，在侧栏底部切换。
- **启动设置**：在「云文档设置」里调整启动时是否打开首页和导航。

支持思源桌面端和桌面浏览器，最低版本 3.8.2。

## 搭配云文档套件

两个插件可同时启用。用「云文档」浏览知识库和目录，在文档树右键选择「创建文件」，即可用「云文档套件」创建和编辑电子表格、思维导图或白板。

[云文档套件](https://github.com/verygoodwu/siyuan-cloud-document-suite)
